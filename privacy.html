Shortkaar privacy policy

Last updated: 17 October 2026

Shortkaar is a private tool that runs on its owner's own computer and works only with YouTube channels the owner connects. This policy explains what Google user data it uses and why.

Google data it accesses

When a channel is connected, Shortkaar asks Google for these permissions:

  • youtube.upload: to upload the owner's videos to the connected channel.
  • youtube.readonly: to read the channel's name, videos and their status.
  • youtube.force-ssl: to set thumbnails, caption tracks, playlists and descriptions on the owner's videos, and to post comments and replies on them.
  • yt-analytics.readonly: to read views and watch time of the owner's videos.

How the data is used

The data is used only to upload and manage the owner's own videos and to learn which of them perform best. It is never used for advertising, never sold, and never shared with anyone.

Where it is stored

The Google sign-in token and the list of uploaded videos are stored only on the owner's own computer. Nothing is sent to any server other than Google's own YouTube APIs.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Removing a channel in Shortkaar also deletes its token from the computer.

Google API Services User Data Policy

Shortkaar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
